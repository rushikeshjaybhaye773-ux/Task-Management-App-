# Task Management Application

## Overview
A full-stack task management application with Google OAuth, Supabase database, and Gmail notifications.

## Features
- Google OAuth 2.0 Login
- Create, assign, and complete tasks
- Gmail notifications on task creation and completion

## Architecture
Google OAuth ↓ Next.js Frontend ↓ Flask REST API ↓ Supabase PostgreSQL ↓ Gmail API

## Tech Stack
- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS
- **Backend**: Flask (Python)
- **Database**: Supabase PostgreSQL
- **Authentication**: Google OAuth 2.0
- **Email Service**: Gmail API
